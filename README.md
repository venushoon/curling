# 🎯 프로 컬링 게임 (React + Canvas 웹 게임)

> [!info] 프로젝트 개요
> **프로 컬링 게임**은 교실 전자칠판(PC) 및 스마트폰 환경에서 구동되는 React 기반의 웹 브라우저용 교육/오락용 게임이다. HTML5 Canvas와 자체 물리 엔진을 활용해 실제 컬링 스톤을 던지는 듯한 슬라이딩, 마찰, 충돌 효과를 구현했다. 자유로운 타겟 설정이 가능한 '컬링 대회(연습)' 모드와 랜덤 점수판 기반의 '팀 대결' 모드를 지원한다.

**태그:** `#프로젝트` `#교육용게임` `#React` `#Canvas` `#물리엔진` `#웹개발`

## 🛠 기술 스택
- **프론트엔드:** React 18 (CDN standalone), Babel
- **렌더링:** HTML5 `<canvas>` API
- **스타일링:** CSS3 (반응형 레이아웃, CSS 애니메이션, Flex/Grid)
- **오디오:** Web Audio API (`AudioContext`를 활용한 동적 사운드 생성)

## ✨ 주요 기능 및 특징

### 1. 두 가지 게임 모드 완벽 분리
* 🎯 **컬링 대회 (연습 모드)**
    * **목적:** 설정한 타겟에 스톤을 정확히 넣는 연습 및 커스텀 이벤트 진행.
    * **기능:** 대회 설정 페이지를 거쳐 진입. 과녁별 이름, 명중 메시지, 커스텀 이미지를 설정할 수 있음.
    * **규칙:** 과녁을 벗어나면 스톤이 제자리로 돌아오며 횟수 제한 없이 계속 투구 가능.
* ⚔️ **팀 대결 모드 (Versus Mode)**
    * **목적:** RED vs BLUE 팀 간의 10라운드 점수 내기 대결.
    * **기능:** 설정 페이지 없이 바로 게임 화면으로 진입하여 빠른 진행 가능.
    * **규칙:**
        * 한 번씩 번갈아 가며 투구 (스톤 색상 자동 변경).
        * 매 턴마다 과녁의 점수(1~6점) 위치가 **랜덤으로 셔플**됨.
        * 과녁에 들어가지 못하면 **0점(낙구) 처리** 후 즉시 다음 턴으로 넘어감.
        * 화면 좌우에 남은 스톤(기회) 10개가 시각적으로 표시됨.
        * 상단 실시간 점수판 및 최종 승리 팀 판별(폭죽 애니메이션).

### 2. 세밀한 물리 엔진 구현 (Physics)
* **드래그 앤 슛 (새총 방식):** 스톤을 터치/클릭 후 뒤로 당겼다 놓으면 반대 방향으로 스톤이 발사됨 (`Math.hypot`, `Math.atan2` 활용).
* **마찰력 & 감속:** 프레임마다 속도에 마찰 계수(`0.985`)를 곱하여 얼음판 위를 미끄러지다 멈추는 효과 구현.
* **충돌 처리:** 경기장 벽(Canvas 경계)에 닿으면 속도가 반전(`-0.7`)되며 튕겨 나오는 바운스 효과 구현.
* **명중 판정:** 스톤의 중심과 과녁 중심 사이의 거리를 계산하여 과녁 반경 내에 스톤이 정지하면 명중으로 판정.

### 3. 고도화된 UI/UX 및 반응형 디자인
* **디바이스 최적화 (Responsive):**
    * **PC/전자칠판:** 가로 화면에서는 세로 비율(1 : 2.5)의 경기장 프레임을 중앙에 배치하고 외부 배경을 노출하여 실제 게임기 같은 느낌 부여.
    * **스마트폰 (모바일):** 좁은 화면에서는 캔버스가 화면 전체(100vw, 100vh)를 채우도록 자동 변환.
* **사용자 편의성:**
    * 하단 플로팅 아이콘 버튼(⚙️ 설정, 🏠 홈)으로 게임 화면(캔버스) 영역을 최대한 넓게 확보.
    * 설정 페이지의 제목과 버튼이 좁은 화면에서도 겹치지 않도록 `flex-wrap` 적용.
* **커스텀 설정 유지보수:** 과녁별 이미지 업로드 시 미리보기 지원 및 직관적인 **삭제(✕) 버튼** 제공.

### 4. 사운드 이펙트 (Web Audio API)
외부 오디오 파일 없이 브라우저 내장 API를 사용하여 즉석에서 효과음을 생성함.
* `play(freq)`: 드래그할 때의 조준음
* `playCollision()`: 벽에 부딪힐 때 나는 둔탁한 타격음
* `playHole()`: 과녁 명중 시 나오는 경쾌한 3연음 성공음
* `playOut()`: 대결 모드에서 과녁을 빗나갔을 때 나오는 하강음(실패음)

## 📂 주요 컴포넌트 구조 (React)

1. **`CurlingApp` (최상위 부모):** 앱의 상태(`page`, `mode`, `layers`, `tournamentTitle`)를 관리하고 화면을 전환하는 라우터 역할.
2. **`Home`:** 게임 시작 및 모드(연습/대결)를 선택하는 메인 화면.
3. **`Setup`:** 연습 모드 선택 시 노출되는 설정 화면. 대회명, 타겟 이름, 타겟 이미지, 성공 메시지를 입력/삭제하는 폼 제어.
4. **`Game`:** 실제 물리 엔진과 Canvas 렌더링이 이루어지는 핵심 컴포넌트.
    * `requestAnimationFrame`을 이용한 60fps 렌더링 루프.
    * 마우스 및 터치 이벤트 리스너 통합 관리.
    * 모드(`mode === 'versus'`)에 따른 조건부 렌더링(점수판 표시, 위치 조정, 0점 처리 로직 분기).

## 💡 개발 회고 및 핵심 트러블슈팅
* **이슈 1: 설정창 제목과 텍스트 잘림 현상**
    * 원인: `white-space: nowrap` 적용 시 모바일에서 화면 너비를 초과함.
    * 해결: `white-space: normal`과 `word-break: keep-all`을 사용해 단어 단위로 깔끔하게 줄바꿈되도록 처리하고 `clamp()` 함수로 동적 폰트 크기 적용.
* **이슈 2: 캔버스 내 과녁과 점수판 겹침 현상**
    * 원인: 상단에 점수판(HTML 요소)을 추가하면서 캔버스 내부의 과녁(Canvas 렌더링 요소)과 Z-축 위치가 겹침.
    * 해결: 모드에 따라 Canvas 내부의 과녁 렌더링 시작 좌표(`startY`)를 다르게 부여(`versus` 모드는 더 아래쪽부터 렌더링)하여 공간 분리.
* **이슈 3: 설정한 이미지가 대결 모드에서도 렌더링되는 현상**
    * 원인: Canvas 렌더링 시 `layers` 배열을 무조건 참조함.
    * 해결: Canvas의 `draw()` 함수 내에서 `mode === 'practice'` 조건일 때만 사용자 지정 이미지와 텍스트를 그리고, 대결 모드일 때는 무시하고 랜덤 점수가 그려지도록 완벽 분리 처리.
